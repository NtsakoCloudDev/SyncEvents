# SyncEvents 🎟️

### A Modern Event Management Platform

SyncEvents is a modern event management web application built with **C# and Blazor WebAssembly**. It provides a clean, user-friendly interface for discovering events, managing event information, and registering attendees.

The project demonstrates the development of an interactive web application using the .NET ecosystem, with a focus on component-based architecture, responsive design, and user interaction.

## ✨ Features

* 📅 **Event Listings** — Browse and explore available events.
* 📝 **Attendee Registration** — Register attendees for events.
* 🎫 **Event Management** — Display event information in an organised interface.
* 📊 **Interactive Dashboard** — View event cards and relevant event information.
* 📱 **Responsive Interface** — Designed for a clean user experience across different screen sizes.
* ⚡ **Blazor WebAssembly** — Build interactive web experiences using C#.

## 🚀 Getting Started

### Prerequisites

Before running the project, ensure you have installed:

* [.NET SDK](https://dotnet.microsoft.com/download)
* [Visual Studio Code](https://code.visualstudio.com/)
* [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/NTSAKO-MILEN/MyBlazorApp.git
```

**2. Navigate to the project directory**

```bash
cd MyBlazorApp
```

**3. Restore dependencies**

```bash
dotnet restore
```

**4. Run the application**

```bash
dotnet run
```

**5. Open the application**

Open the local URL displayed in your terminal, typically:

```text
http://localhost:5222
```

The actual URL may differ depending on your launch configuration.

## 📂 Project Structure

The application uses Blazor's component-based architecture to organise its interface and application logic.

* **Pages/** — Contains the application's pages and routes.
* **Layout/** — Contains shared layout components.
* **Components/** — Contains reusable interface components.
* **Models/** — Defines the data structures used by the application.
* **Services/** — Contains services responsible for application functionality.
* **wwwroot/** — Stores static assets such as CSS, images, and other web resources.
* **Program.cs** — Configures application services and startup behaviour.

*Note: The exact folders may vary depending on the project structure.*
